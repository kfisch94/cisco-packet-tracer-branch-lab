# Reference images

The four small CLI images were supplied as reference illustrations for the personal README commentary. They are separate from the lab-result screenshots in evidence/.

The installed-switch-base chart is credited to Computer Profile / Smart Profile. The matching primary research is dated April 2018 and describes Dutch organizations with more than 50 employees: https://smartprofile.io/analytics-papers/ciscos-share-in-networking-equipment-continues-to-decline/

The 54.5% figure concerns the inventoried switch installed base in that study. It is not a current global market-share claim. Third-party reference imagery is not part of the original lab starter's MIT license.

## DHCP and transport reference illustrations

`dhcp-topology-reference.png`, `tcp-tls-reference.png`, and `udp-reference.png` are supplied explanatory illustrations, not screenshots of completed tests in this branch lab. Their original creators/URLs were not supplied; no authorship is claimed. The TLS timing example is schematic and condenses TCP establishment. Protocol explanations link to the IETF/RFC Editor primary specifications. These reference images do not establish DHCP, TCP application, UDP application, or TLS validation in this project.
